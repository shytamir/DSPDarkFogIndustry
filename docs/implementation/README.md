# Implementation records

Use this directory for technical contracts and evidence associated with authorized
work. [PROJECT.md](../PROJECT.md) owns activation, progress, decisions' dispositions,
acceptance, and closure.

For each meaningful record, identify the work ID, source/build and runtime inputs,
mechanism or contract, why it satisfies the approved outcome, validation actually
performed, results and limits, and any short owner procedure. Link to evidence
rather than duplicating it. Do not create an architecture before planning calls for it.

Archive completed records with their plans under [archive](../archive/README.md),
except technical contracts that still govern the maintained implementation.
