# Work item template

Copy only for an authorized planning task. Replace prompts with concrete decisions;
do not create speculative stories to fill this template. State lives in
[PROJECT.md](../PROJECT.md).

## ID and outcome

Stable ID, title, and the player or maintainer outcome being enabled.

## Scope and exclusions

Exact behavior/artifacts covered and explicit adjacent work excluded.

## Dependencies and unresolved questions

Required prior outcomes, native evidence, and owner decisions. Identify the early
check that resolves each consequential unknown; define when to stop and report.

## Definition of done

Observable acceptance criteria, including negative cases and native behavior to
preserve. State what compilation cannot establish.

## Validation and handoff

Focused automated checks; any coherent owner-run procedure; artifact identity;
required evidence and its limits. Avoid a broad runtime matrix without a reason.

## Technical references

Link relevant source and supporting evidence. Keep algorithms, hooks and constants
in code, with rationale beside the implementation where useful.
